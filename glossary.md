# Tally Aloft — Glossary

Aviation and regulatory terms used across these documents.

| Term | Meaning |
| --- | --- |
| 8710 / IACRA | FAA Form 8710-1, the application for a pilot certificate or rating, and IACRA, the FAA's online system for filing it. Both ask for a summary of flight time. |
| AC 120-78B | The FAA advisory circular that describes acceptable electronic signatures and records. |
| ADS-B | The broadcast that aircraft send out with their position, which flight-tracking services collect. |
| CFI | Certificated flight instructor. |
| EASA | The European Union Aviation Safety Agency. |
| EFB | Electronic flight bag: apps such as ForeFlight and Garmin Pilot used for planning and navigation. |
| ICS | The standard calendar file format, which many airline scheduling systems can export. |
| LADD | The FAA's Limiting Aircraft Data Displayed program. Owners can ask for their aircraft to be hidden from public flight tracking, and data vendors must honor the list. |
| OpSpec A025 | The part of an air carrier's FAA operations specifications that authorizes electronic signatures and records. |
| Part 61 / 91 / 121 / 135 | Sections of the FAA rules (14 CFR): pilot certification, general operating rules, airlines, and commuter and on-demand operators. |
| Part 117 | The FAA's flight and duty time limits for airline pilots. |
| PIA | Privacy ICAO Address: a temporary aircraft address that keeps an aircraft from being linked to its registration in flight tracking. |
| REED | Recent Experience End Date. Since December 1, 2024, flight instructor certificates no longer expire. Instead, an instructor has to show recent experience every 24 calendar months, and the REED is the date by which they must. |
